# Interface glossary (English → Ukrainian)

One term — one translation, everywhere (owner, D30). Messages live in `src/i18n/messages/{uk,en}/`. Service
names (LinkedIn, Indeed, Glassdoor…) are not translated. Dates: `14.10.2026`, «14 жовт.»; weeks start on Monday;
time is 24-hour in Ukrainian (D36).
