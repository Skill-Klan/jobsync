# Translations

- Messages: `src/i18n/messages/{uk,en}/<section>.json`. `en` is the original English text (the test suite
  runs in English), `uk` follows `docs/glossary.md` — one term, one translation, everywhere.
- A new key goes into **both** languages. The parity test wants the same keys, the same ICU arguments and
  tags, nothing empty, `uk` ≠ `en`, and every message parsed by `intl-messageformat` — the same parser the
  app uses. Never read ICU arguments with a regex.
- `t("…")` keys are typed: a key missing from the messages is a `tsc` error (`npm test` won't show it).
- ICU: an ASCII apostrophe escapes — `'{name}'` prints the literal `{name}`; quote an argument with `''{name}''`.
  The Ukrainian apostrophe `ʼ` (U+02BC) is a letter and safe. Ukrainian plurals have four forms:
  `one {# вакансія} few {# вакансії} many {# вакансій} other {# вакансії}`.
- Owner's choices: «AI», not «ШІ» (D34); «навички», not «теги» (D35); 24-hour time in Ukrainian, as before
  in English (D36); resume and cover-letter PDFs stay in English except the student's own text (D37);
  dates `14.10.2026`, weeks start on Monday.
- zod's `z.config({ localeError })` is global — on the server too; `src/i18n/validation.ts` keeps zod's own
  English messages where there is no `document`.
